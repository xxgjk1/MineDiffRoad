# MineDiffRoad

## 保守标注下可靠性引导的矿山道路分割

[English](README.md) · [论文结果](docs/PAPER_RESULTS.md) · [17张论文配图](docs/FIGURES.md) · [实现说明](docs/IMPLEMENTATION_NOTES.md)

保守标注会遗漏道路边缘和受遮挡区域。把所有未标注像素当作背景，会压制真实道路的恢复。MineDiffRoad 利用 RGB 与实测 LiDAR 的局部可靠性，筛选背景监督位置，并从保留的未知区域提取道路恢复目标。

![图3：MineDiffRoad的训练与推理流程。](docs/figures/figure_03.png)

## 模型配置

输入／评价网格为 1024×1024，融合网格为 256×256，使用完整四阶段 MiT-B0 及 LitePT-S。图像保比例缩放后补边或裁剪，标定同步变换，补边不计入监督或评价。

## 方法

| 项目 | 当前实现 |
| --- | --- |
| 图像骨干 | 完整四阶段 MiT-B0，各阶段汇合至 stride 4 |
| 可靠性头 | 两个头均读取联合图像、点云及支持特征 |
| 融合 | 可靠性加权后拼接，再经投影 |
| 几何环带 | D25(M⁺) 减去核心 M⁺，没有内层间隔 |
| 环带外背景 | B_out 始终保留硬负监督 |
| 环带内准入 | 双教师稳定背景，双模态可靠性均满足阈值 |
| 未知区域上限 | 按原始有效图像面积，仅从环带外侧向内收缩，保持紧邻道路核心的未知内侧层；执行满足30%上限所需的最少次数 |
| 腐蚀移除区域 | F⁻ 回到普通背景，不混称为可靠性准入 |
| 完整负监督 | M⁻ = B_out ∪ S⁻ ∪ F⁻ |
| 恢复候选 | 面积限制之后，在 Mᵘ 内选择 Q⁺ |
| 部署 | 移除重建和教师，保留直接预测与有界残差 |

K = M⁺ ∪ M⁻ ∪ Q⁺ 是训练有效集合。集合外的0.5只是填充值。面积上限的分母是原始有效图像，不是环带。裁掉的原图区域仍保留在该分母中，补边不贡献面积。

## 论文结果

以下指标单位均为百分比。

| 全训练方法（表1） | IoU | MR | EP |
| --- | ---: | ---: | ---: |
| Concat | 63.58 | 71.42 | 46.93 |
| Conf | 64.94 | 73.68 | 50.87 |
| 仅可靠性准入 | 67.61 | 76.84 | 53.73 |
| MineDiffRoad | **68.57** | **79.13** | **55.12** |
| 完整标注参考模型 | 69.21 | 80.42 | 55.79 |

| 60%固定配额（表2a） | FNS | BR | IoU |
| --- | ---: | ---: | ---: |
| 随机选择 | 2.13 | 60.03 | 65.44 |
| 置信度选择 | 2.16 | 60.52 | 66.14 |
| MC不确定性，8次前向 | 2.03 | 60.93 | 66.91 |
| 可靠性选择 | **1.72** | **61.08** | **68.76** |

固定配额采用共同教师、候选域和正候选，不同于独立演化教师的全训练。FNS只审核共同候选域中的入选负样本，不含环带外背景和面积限制恢复的背景。FNS、BR、MR、EP按有效图像平均。IoU先在种子内汇总像素计数，再平均五个种子。

![图7：面积限制前的固定配额选择。](docs/figures/figure_07.png)

灰色是未入选候选，不等于最终未知掩膜。紫色仅用于完整参考支持的离线审核。全部统计范围见[结果说明](docs/PAPER_RESULTS.md)。

## 使用

安装、训练、评价、导出命令见[英文README](README.md#run-the-source)。真实LitePT需要兼容的CUDA与spconv。CPU可运行监督、几何、图像骨干、损失及统计检查。

- [数据格式](docs/DATA_FORMAT.md)：真实RGB、LiDAR、标定和分组清单。训练记录禁止完整参考标签。
- [默认配置](configs/paper.yaml)：模型结构、监督规则及训练参数。
- [示例配置](configs/example.yaml)：继承默认训练参数，运行前需提供完整MiT-B0 ImageNet权重。
- [统计接口](docs/STATISTICS.md)：真实逐帧、逐种子、逐场景计数，配对t区间及场景—种子交叉bootstrap。
- [测试记录](docs/SOFTWARE_VALIDATION.md)：本次CPU检查和旧版CUDA记录分开列示。

论文使用的 SegMine 工作子集为 **749 帧**、26 个场景、12 个采集组；训练／验证／测试分别为 524／75／150 帧。这是所附论文使用的、具有对应点云的工作子集，不代表 SegMine 其他数据产品的规模。提供实际清单后，可运行 `python -m minediffroad verify-data --manifest data/manifest.jsonl --paper-segmine` 核对帧数、场景数与采集组数；普通数据加载仍以清单为准。

`verify-data --paper-core-equality` 可逐像素检查验证／测试的 `core` 与 `evaluation_core` 是否一致；`--natural-degradation-ids data/natural40.json` 可检查自然退化40帧是否全属独立测试集。两项检查都需要提供对应的真实清单，参见[数据格式](docs/DATA_FORMAT.md)。

默认训练参数如下，Conf与Concat配置继承相同的优化器设置。

| 参数 | 默认值 |
| --- | --- |
| 优化器 | AdamW |
| 学习率 | 1 × 10⁻³（`0.001`） |
| 权重衰减 | 1 × 10⁻⁴（`0.0001`） |
| 学习率调度 | 恒定，不使用退火 |
| 训练轮数 | 400 |
| 批量大小 | 2 |

配置中的余弦偏置仅用于扩散噪声日程，不影响优化器学习率。

在线训练、Conf准入、拼接融合、固定配额排序及FNS/BR审核接口已提供。

[原Conf配置](configs/conf.yaml)沿用论文表格中的95%背景置信度定义。[同阈值Conf配置](configs/conf_matched.yaml)与可靠性方法共用教师道路概率小于0.10的准入条件，供重新训练和评价；它不沿用原Conf的结果数值。
