# Paper tables in CSV format

These files contain table values transcribed from the supplied manuscript. They are organized by the original table/panel number and are not per-run training logs. For metric definitions, protocol differences, and table footnotes, use [PAPER_RESULTS.md](../PAPER_RESULTS.md).

All numeric precision is preserved. Headings include units and metric directions. Tables 1–6 produce 11 CSV files because Tables 2, 3, 5, and 6 contain multiple panels. Source identifiers and hashes are in [ASSET_PROVENANCE.json](../ASSET_PROVENANCE.json).
