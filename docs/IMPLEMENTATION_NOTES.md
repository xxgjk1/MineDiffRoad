# 文稿定义与实现选择

实现对应 `main(2).tex` 中的方法定义；层配置和增强分布参考补充材料。下文记录模块接口、配置约定和具体实现选择。

## 已按文稿固定的部分

1. 所有道路监督规则作用于输入图像网格，正式配置 512×512；融合网格 128×128。
2. `D25(core) & ~D11(core) & ~core & Omega`；25、11 是方形核宽度，不是半径。代码没有额外读取完整标注来排除天空。
3. 第 1–10 epoch 负监督为几何环带，无 EMA 筛选、无正候选重建；第 11 epoch 开始复制学生分割路径创建 EMA=0.99。
4. 负监督要求两教师概率均小于 0.10，且两模态有效可靠性均大于 0.50。正候选位于未知域，两教师概率均大于 0.90、差小于 0.05，且至少一模态可靠性大于 0.50。
5. 正核心目标 1，负监督目标 0，候选目标为两个教师的均值；其余填 0.5，但不属于有效集合 K。
6. 可靠性代理不读取道路完整标注；对退化前有观测的位置监督 ungated head，点云有效可靠性乘退化后支持。上采样后再次以最近邻支持掩膜门控，防止双线性插值把可靠性扩散到无点像素。
7. 分割与目标迁移为逐图 class-balanced BCE + Dice，再平均非空图；空集合贡献 0，单一类别 BCE 不除以 2。
8. 余弦日程 T=1000、s=0.008，每个 batch 共享一个随机 t；x0 使用 [0,1] 目标，不转换成 [-1,1]。训练预测噪声并恢复 x0，迁移到分割时 detach；噪声与重建损失仍更新条件特征。
9. 恢复门控由整个 batch 是否存在正候选决定。重建绝对误差分别对核心/候选和负监督求均值，再对两项取 1/2，空项按 0 处理。
10. 最后残差层零初始化；`delta = 0.1*(1-|2*Pb-1|)*tanh(h)`；单次前向 logit 改变量 ≤0.1、概率改变量 ≤0.025。
11. 部署仅保留编码、可靠性融合、基础分割和有界残差；没有迭代去噪或测试标签访问。

## 文稿不充分确定、此实现明确选择的部分

| 项目 | 实现选择及影响 |
|---|---|
| 图像骨干接口 | 补充材料指定“stride-4 stage”。使用 MiT-B0 的 patch_embed1、block1 两块、norm1，然后 32→128 投影。没有完整 SegFormer 解码器，也没有添加多尺度融合。此接口使用第一阶段特征；与完整多尺度 SegFormer 配置的参数量和计算量有所区别。 |
| LitePT 配置 | 官方默认 S 拓扑：编码通道 36/72/144/252/504，深度 2/2/2/6/2，解码输出 72；从零训练。voxel_size=0.05 米为显式配置，文稿未唯一指定。 |
| FPS 与体素 | FPS 固定起点为离质心最远的点。体素内取原始顺序首点作编码输入，逆映射恢复每个采样点特征；没有在 RGB 中伪造点云。点数不足时不重复补齐。 |
| 像素投影 | 相机坐标 z>0；四舍五入到像素中心；每像素保留距最近深度不超过 0.50 米的点，然后按 4×4 cell 聚合均值和最大值。 |
| 点坐标噪声 | 归一化标准差乘 `coordinate_noise_scale_m` 转成米，默认 1.0。文稿没有定义归一化尺度，真实实验前必须依据数据约定冻结，并记录所采用的物理尺度。 |
| 局部丢点比例 | 在退化前可见点及其投影 cell 上统计保留比例，避免坐标抖动被误计为 dropout；坐标噪声另按 sigma²/.05² 计入。 |
| 图像几何 | 原始 RGB 先按共享随机尺度变为方形，再共享裁剪/补零与翻转；每一步同步更新 K。补零处 Omega=0。对非方形数据，此方案会改变横纵比例；文稿没有给出原始长宽比处理规则。 |
| 图像模糊 | Pillow GaussianBlur 实现，sigma 按文稿采样；遮挡使用随机长宽比矩形，面积按离散像素取整。 |
| 结构边界损失 Lb | 对预测与目标的 3×3 膨胀减腐蚀边界取 masked L1；支撑是 E3(K)。文稿未给出该损失的唯一范数形式。 |
| 骨架 Ls | 3×3 方形 soft erosion/opening，默认 10 次；每一次形态操作均侵蚀有效支撑，最终以各次有效支撑的交集计算 soft clDice。这比简单 masked skeleton 更保守；窄有效区域可能没有骨架损失。迭代数未见唯一说明。 |
| 一致性 Lc | 对 K 中 `Pb≥0.9` 或 `Pb≤0.1` 的像素，计算 `mean((Pf-stopgrad(Pb))²)`；阈值与具体范数属于明确实现选择。 |
| 残差正则 Ldelta | K 上 mean(delta²)；范数在文稿中未展开。 |
| 重建空间尺度 | condition、下采样 xt 和噪声预测网络在融合网格计算，噪声预测再双线性上采样到输出网格；这是按补充表的 128×128 condition 接口补全的选择。高频噪声预测受这一分辨率限制。 |
| 重建残差块 | GN–SiLU–Conv 两次，FiLM 在第一个 GN 后注入；表中未展开块内顺序。 |
| 余弦终点 | alpha_bar 下限 1e-6，避免 t=1000 理论零值除法；配置与 checkpoint 保存该值。 |
| 优化细节 | lr=6e-5、wd=.01 是候选设置；单一 AdamW 参数组、epoch 级余弦退火、梯度范数裁剪 1.0 是补全选择。最终选值应随实验配置记录。 |
| 最佳 checkpoint | 用全局 Road IoU 选择；0.02 个百分点内偏好更早 epoch。指标另存逐图均值，避免混用。无验证集不选优。 |
| 结果后处理 | 二值阈值 .5，8 连通分量小于 50 像素删除；Boundary F1 容差默认 2 像素是补充诊断设置。 |

## 运行与实验接口

- 固定随机种子、数据增强种子、FPS 起点和推理序列化顺序，并记录运行环境。CUDA/spconv 的并行归约可能引入微小数值差异。
- 部署路径在 eval 模式下禁用 DropPath 和 LitePT 序列化随机重排。两教师视图使用同一像素几何坐标。
- CPU 测试中的小骨干用于隔离测试；训练、评估和推理入口使用 LitePT-S。
- 主训练入口实现在线教师协议。`fixed_quota_selection` 提供固定配额原语；论文的轨迹 replay 需要共享教师缓存和对应实验驱动。
- 数据集、图像预训练权重和实验 checkpoint 由使用者准备。文件输入格式见 `DATA_FORMAT.md`。

## 指标的空集合约定

在有效域 Omega 内，前景预测与 GT 都为空时 Road IoU 和 Dice 为 1；GT 有前景而预测为空时 Precision=0、Recall=0。GT 为空时 Recall=1，Precision 仍按预测计算。背景 IoU 同理；mIoU 是前景和背景 IoU 均值。完全没有有效评价像素的图像报错，不静默加入平均。Boundary F1 在两侧边界皆空时为 1，一侧为空时为 0。
