# 模型实现与训练配置

本文件说明模型结构、监督规则、训练配置和统计接口。版本与来源信息见 [SOURCE_SPEC.json](SOURCE_SPEC.json)。

## 模型与监督规则

1. 输入及评价网格1024×1024，融合网格256×256，每路投影为128通道。图像骨干包含完整四阶段MiT-B0，不再只实例化第一阶段。点云骨干为LitePT-S。
2. 图像保比例缩放后补边或裁剪。RGB、核心、完整参考、有效域及评价核心使用相同几何，K同步左乘变换矩阵。LiDAR物理坐标不做不匹配的水平翻转。默认按原图像素中心约定更新主点。
3. 环带为 D25(M⁺) 减去 M⁺，并与Ω相交。25是方形核宽度，不存在D11内层间隔。B_out始终保留硬背景。
4. S⁻要求两个教师道路概率均小于0.1，且两模态可靠性均大于0.5。U为其余环带。以道路核心为中心，从外向内逐层收缩 U，保持紧邻核心的内侧边界不变；按原始有效图像面积执行满足30%上限所需的最少次数。若内侧保护带本身超过上限，程序报错，不会暗中侵蚀内边界。F⁻为移除区域，恢复普通背景。M⁻=B_out∪S⁻∪F⁻。
5. 面积限制之后才在Mᵘ中选Q⁺：两教师概率均大于0.9、差小于0.05、至少一模态可靠性大于0.5。目标为停止梯度的教师均值。所有阈值严格比较。
6. 两可靠性头都读取联合特征C。点云可靠性乘支持掩膜，上采样后再次门控，防止插值把可靠性扩散到无支持位置。融合采用加权后拼接和投影。
7. 当前投影配置仅保留每像素最近深度（depth_tolerance_m=0）。同深度返回允许保留，融合格内进行均值／最大值聚合。空格填零并记录支持。
8. K=M⁺∪M⁻∪Q⁺，未知填充值0.5不是标签。结构损失传播有效域。重建迁移目标停止梯度，其他重建损失仍可更新条件特征。
9. 有界残差使用0.1×(1−|2Pb−1|)×tanh(h)，末层零初始化。单次logit改变量不超过0.1。推理移除教师和重建分支。
10. 评价在1024网格排除补边。IoU按种子汇总像素计数，MR/EP逐图计算并排除未定义分母。FNS/BR只审核共同候选域中的入选负样本，不混入B_out和F⁻。

## 具体实现约定

| 项目 | 本仓库约定 |
| --- | --- |
| 四阶段汇合 | MiT-B0各阶段输出32/64/160/256通道，上采样到stride 4后拼接为512通道，再线性投影到128。 |
| 原始面积计量 | 对原始有效像素中心应用几何变换，将其分配到最近工作网格像素。加权求和等价于最近邻回映未知掩膜。裁掉的像素只计原始面积分母，补边权重为0。 |
| 未知区域腐蚀 | 默认3×3方形核，以道路核心的切比雪夫距离确定外侧层，每次只去掉最外一层；已准入的背景孔洞不会引发内侧腐蚀。每图独立求最少次数。 |
| 几何增强 | 默认fit后补边，亦可选择fill后裁剪。训练尺度扰动0.9–1.1，共享裁剪／补边／翻转；评价采用确定性中心位置。 |
| 预热及EMA | 默认10个epoch预热、EMA衰减0.99。预热时环带及外部均为背景；随后由学生分割路径初始化教师。 |
| LitePT输入 | 16,384个FPS采样点；不足不重复补齐。体素0.05米，体素中首点编码并逆映射。FPS从离质心最远点开始。 |
| 退化 | 40%无额外退化、25%图像、25%点云、10%联合。质量代理不读取完整道路标签。 |
| 点坐标噪声 | coordinate_noise_scale_m默认1.0米，用于将归一化坐标噪声换算为米。 |
| 重建 | T=1000、余弦偏置0.008、alpha_bar下限1e-6，每batch共享采样时间，使用[0,1]目标。条件及噪声预测在融合网格，输出上采样到图像网格。 |
| 损失具体形式 | 分割为逐图class-balanced BCE+Dice。边界用masked L1，骨架默认10次形态学迭代，有效域逐步收缩。一致性和残差正则使用平方误差。 |
| 优化器 | AdamW单参数组、恒定学习率、不使用学习率余弦退火、梯度范数裁剪1.0。学习率1e-3，权重衰减1e-4，批量大小2；paper.yaml、example.yaml、conf.yaml及concat.yaml使用相同默认值。扩散噪声日程的余弦偏置与学习率无关。 |
| 模型选择／后处理 | 全局道路IoU选优，0.02个百分点内偏好较早epoch。阈值0.5，小于50像素的8连通分量删除。补边先移除，避免其连接两个小分量。 |
| 软件版本 | 当前仓库要求PyTorch≥2.4及兼容的CUDA、spconv和cumm。论文附录的PyTorch 2.1.2、CUDA 12.1是时延测量工作站的环境记录，不能把当前软件验证环境误写成该时延测量环境。 |

## 控制实验与统计

- 默认在线训练使用可靠性准入。`configs/conf.yaml` 保留论文现有 Conf 定义：共同环带内“有点支持且双视图背景置信度大于0.95”。该阈值与可靠性方法的教师道路概率小于0.10并不相同，因此该实验不能单独识别可靠性门控的因果贡献。
- `configs/conf_matched.yaml` 新增严格同阈值的 Conf 控制：两教师道路概率均小于0.10并有点云支持；与可靠性方法仅在是否进一步要求两模态可靠性通过门限上不同。该配置需要独立训练和评价，不能沿用原 Conf 行的论文数值。
- feature_fusion=concat提供无权拼接控制。
- fixed_quota_selection仅负责域内每图精确floor(配额×候选数)的排序。可靠性排序应传min(rv,ra)，置信度排序应传共同教师背景置信度，均不得读取完整参考。
- selection_diagnostics在筛选完成后离线计算FNS/BR。参考标签只用于审核。
- 统计接口读取逐帧混淆计数及场景ID，计算配对t区间和场景—种子交叉bootstrap。见[统计说明](STATISTICS.md)。

## 兼容性

旧第一阶段checkpoint不能作为四阶段模型加载。完整ImageNet MiT-B0权重严格检查各阶段键和可选SHA256。当前训练checkpoint格式为3，保存实际运行配置；带学习率调度器状态的旧训练checkpoint不可用于当前恒定学习率协议续训。CPU小骨干仅用于隔离测试，实际入口不会静默替代LitePT。

完全没有有效像素时评价报错。前景预测和参考同时为空时IoU/Dice取1。MR、EP、FNS、BR的未定义分母返回None，不伪装成0。CUDA稀疏归约不保证跨环境逐位一致。
