## 当前版本：2026-10-22

本次在Windows、Python3.12.14、PyTorch2.14.1+cpu、NumPy2.3.5、SciPy1.18.1、Pillow12.3.0、PyYAML6.0.3下检查。测试输入为合成张量及临时文件。

执行命令：

```bash
python -m unittest discover -s tests -v
python -m minediffroad --help
```

本轮结果：47项中44项通过，3项需要真实CUDA或完整训练环境的测试未运行。CLI帮助检查通过。测试未使用749帧数据清单或原始训练日志。

覆盖：

- 完整四阶段MiT-B0在1024×1024上的输出尺寸，以及四阶段反向梯度。
- 完整ImageNet权重键检查，拒绝旧第一阶段权重。
- 紧邻道路核心的环带、始终保留的外部背景和监督集合分区。
- 30%面积上限、逐图控制、原始有效面积加权及从外侧向内的最少次数收缩；核心邻接层不被侵蚀，面积上限不可同时满足时明确报错。
- SegMine 2048×1536、RELLIS-3D 1920×1200的保比例几何及相机内参变换。
- SegMine 工作子集的524／75／150帧、17／3／6个场景、8／2／2个采集组；可选清单核对会拒绝帧数错误、缺失场景标识和场景跨划分。
- 原Conf准入、同教师阈值Conf控制、无权拼接、训练预热及预热后的损失反向传播（点编码使用显式测试替身）。
- 评价核心逐像素相等性审核和自然退化40帧独立测试划分审核的合成输入测试；实际论文数据仍需提供对应清单才能核验。
- FNS/BR与MR/EP的分母、空集合和无效域处理。
- 逐帧评价保存scene、seed及混淆计数；配对t和交叉bootstrap的配对、像素重汇总与可重复性。
- 批量大小2、恒定学习率1e-3、权重衰减1e-4及配置继承；缺失优化器参数与误设余弦学习率调度的拦截；所附40页论文17张配图和11份结果CSV的哈希及文档链接。
- 原有投影、稀疏算子兼容层、EMA、重建梯度、残差上界及训练参考标签访问限制。
